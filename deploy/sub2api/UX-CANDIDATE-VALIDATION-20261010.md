2026-10-10，已构建的原生 Vue 候选。此文件不代表已发布；本轮没有重启或改写生产。

已接入的功能：

- 用户和管理员工作台复用旧四条 Codex / WorkBuddy Windows / macOS 安装命令，保留原作者与 AGPL 声明。Key 按服务端真实个人/团队范围分页；默认掩码，明确显示/复制时再读取并校验所有者、范围、状态、过期时间。切换用户、Key、范围、系统、客户端及卸载组件会清除已显示凭据。零余额不阻止配置；没有团队 Key 不使用个人 Key 代替。
- Key 页面显示真实范围，并将个人/团队筛选交给服务端执行，保持分页与总数一致；不以分组推断范围。
- 团队成员 ID 在昵称前显示；支持周上限、周已用、可用、累计费用、累计 Token 排序。昵称通过团队成员接口修改，仅团队内生效，最多 40 个 Unicode 字符，空值清除别名；普通成员不显示管理操作。累计值来自团队权限范围内服务端汇总，缺失值显示未知。
- 工作台及订阅页读取 `payment/managed-subscriptions` 的真实个人权益，显示本周可用、下次周重置、到期；不显示月总额替代可调用余额。加载失败和成功空集分开。服务器明确返回非托管身份时保留原生订阅页。
- 购买卡和确认页读取 managed entitlement，CNY 售价只转换一次，权益按显式客户汇率展示。个人购买走原生订单 API；钱包完成状态确认后进入原生结果页。重试和 OAuth 返回复用同一幂等键，变更操作者、计划、付款来源时新建键。团队首购、续费、升级、退款以服务端真实 capability 为准，当前不支持的动作不会开放。
- 管理员 RealYu 套餐表单使用 active standard 分组、28 天周期、精确周额度乘 4、人民币售价。先下架保存原生计划，再配置 managed metadata；不会自动上架。配置失败保留草稿 ID 供重试，管理员核对后才从原生列表上架。原生套餐编辑器保留。
