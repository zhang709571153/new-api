## 1. 公开 HTML 的实际实现

源码路径均相对于按 [Prepare-SingleCore.ps1](Prepare-SingleCore.ps1) 恢复出的**原生源码目录**，不是本交接仓的旧 React `web/` 目录。

| 页面 | 不执行 JavaScript 时的正文 | 当前边界 |
| --- | --- | --- |
| `/home`，以及 `/`、`/home/` | 站点说明、公开导航、原生模型价格表及实际计费说明 | 根路径和尾斜线的 canonical 统一为 `/home`；这里不是为用户输出余额、Key 或累计用量。 |
| `/pricing`、`/pricing/` | 模型 ID、输入/输出/缓存价格、实际阶梯区间，非 Token 模式的单次价格 | 价格来自配置的个人标准组；不是登录用户的专属报价或供给账号成本。未知价格不伪造为零。 |
| `/docs`、`/docs/` | 四步接入、客户端/系统操作、手动配置说明与 FAQ 的静态文本 | 读取构建内的中英文文档 JSON；不读取任何用户 Key，也不为 SEO 调用模型。 |

入口是 `backend/internal/web/realyu_public_seo.go` 与 `embed_on.go`。Go 服务在嵌入的 `index.html` 中写入可抓取正文、标题和 metadata，再由 Vue 接管交互；这是服务端预渲染正文，并非新增一套 Vue SSR 服务。

启用条件为：构建带 `-tags embed`、公开目录 provider 已接线、原生公开设置中的 `site_logo` 指向 `/brand/realyu-wordmark.png`、请求是上述明确路径的 GET/HEAD。普通自定义品牌不会仅因含有这些资源而自动使用 RealYu SEO。Vite 开发服务器和不带 embed 的 Go 构建不能代替此验收。

公开 HTML 返回 `Content-Language`、`X-Robots-Tag: index, follow` 和 `Cache-Control: no-cache`。获取设置/目录使用有界上下文；目录不可用时页面说明价格暂不可用，不使用备用假价格。SSR 对模型名称、标题、段落做 HTML 转义，并沿用请求 CSP nonce。canonical 使用固定受控域名，不反射请求 Host。

## 3. 私有页面与公开数据白名单

非公开 SPA 页面，包括工作台、调用记录、团队、管理员、登录及未知 SPA 路径，在嵌入前端响应中设置 `X-Robots-Tag: noindex, nofollow`。客户端从公开页进入私有页时，清除本轮添加的 canonical、alternate、Open Graph/Twitter 与 JSON-LD，并设置 robots noindex。不能因页面外壳返回 HTTP 200 就认为私有 API 可匿名读取；登录、管理员角色与服务端 actor/team 过滤继续独立生效。

`frontend/public/robots.txt` 当前只有 `User-agent: *`，禁止抓取 `/api/`、`/v1/`、`/admin/`、`/auth/` 以及工作台、用量、团队、Key、个人资料、订单、订阅、购买、登录、注册、Key 用量和 setup 等路径，并指向 sitemap。它没有单独声明 GPTBot 训练退出。

robots.txt 是抓取指示，不是保密控制。被 Disallow 的 URL 可能无法让爬虫看到 noindex；因此不能保证一个已被外链提到的私有 URL 永远不会出现在搜索结果中。客户数据的保护依靠认证、服务端权限与不把私有数据写入公开 HTML。若发生已收录 URL 问题，按真实搜索控制台结果处理，不能通过放开客户接口让爬虫读取数据。[Google noindex 说明](https://developers.google.com/search/docs/crawling-indexing/block-indexing)

匿名 `GET /api/v1/realyu/public-models` 使用 PublicIP 限速和 `Cache-Control: public, max-age=60`。服务端先读取 `realyu_signup_personal_group_id`，在托管模式下仅发布该明确标准组的公开定价；配置或目录不满足时返回 503。数据合同为：

| 层级 | 允许字段 |
| --- | --- |
| 顶层 | `currency`（USD）、`price_unit`（million_tokens）、`models` |
| 模型 | `id`、`pricing_type`、`input_price`、`output_price`、`cache_read_price`、可选 `per_request_price`、`has_adjustments`、可选 `intervals` |
| 阶梯 | `min_tokens`、可为 null 的 `max_tokens`、`input_price`、`output_price`、`cache_read_price` |

这个 DTO 不含 user/team/group/account/channel/provider ID、个人倍率、钱包、成员历史、代理地址、API Key、OAuth 或供给凭据。原生 `__APP_CONFIG__` 仍走现有公开设置 DTO；公开目录不是整份管理员设置导出。SSR 与浏览器 JSON 使用同一目录来源。

Token 价格按当前公开组倍率及“百万 Token”单位换算一次；媒体单次价格使用该媒体适用倍率。`has_adjustments` 标识动态调整，阶梯价格保留实际区间。前端简单估算仅适用于无调整、无阶梯且价格已知的 Token 模式；它不是结算承诺。客户消费记录继续按明确配置显示人民币，公开模型单价保留美元。

## 4. GEO 与爬虫策略的含义

本轮采用可读正文、真实信息、清楚导航与 metadata 的基础 SEO。Google 官方说明，这些原则同样适用于其生成式搜索；满足技术要求也不保证抓取、索引或展示，不需要专用 AI schema。[Google AI optimization guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)

`llms.txt` 是本站额外提供的公开内容索引，列出首页、价格、文档与计价说明。它不是新搜索协议、排名信号或收录回执。Google 明确表示其 Search 不使用 llms.txt；维护此文件不会因此增加或降低其搜索可见性。文件可供其他工具自行使用，不能宣称所有 AI 产品支持它。[Google 对 llms.txt 的说明](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide#mythbusting-generative-ai-search-what-you-dont-need-to-do)

OpenAI 的 `OAI-SearchBot` 用于搜索，`GPTBot` 用于可能参与模型训练的抓取，两者设置独立；`ChatGPT-User` 是用户触发访问，不能拿它代替搜索抓取控制。目前通用 robots 规则未单独退出 GPTBot。若后续要区分“允许搜索、禁止训练”，应另行审核 robots 与 CDN/WAF，并参考官方发布的 IP 范围；仅伪造 User-Agent 的本机 curl 不能证明官方机器人实际可达。[OpenAI Crawlers 文档](https://platform.openai.com/docs/bots)
