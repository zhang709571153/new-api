# Windows 1.4.27 系统代理验收

版本：realyu-provider-v3.9.2.12-20261007。配置和图片组件无需 Python/Node，总下载量小于200 KB。Mac保持1.4.26。

1. 保持Windows已配置的系统代理开启，记录代理是否启用即可，不提交凭据。关闭Codex/WorkBuddy再运行原官网安装命令，确认版本1.4.27和明确完成状态。
2. 下载应显示总大小、速度及“下载遵循Windows系统代理设置”，大小和SHA256校验通过。安装器密钥检查及图片诊断均继承Windows当前用户的默认代理；没有系统代理或命中系统旁路规则时直连。不读取shell HTTP_PROXY作为通用替代规则。
3. 重开应用并新建对话，调用一次diagnose_image，确认version=1.4.27、proxy_policy=windows_system、四项passed。proxy_policy说明策略，不是当前请求经过代理的独立证明。
4. 仅提交一次“生成一只骄傲的小公鸡”，不要自动重试。记录request_id、耗时；必须有原图和512px以内预览，并在桌面实际显示。分别报告文件解码、MCP图片结果、桌面显示是否通过，不能互相替代。
5. 若仍失败，保留原始错误及request_id，先查服务端结果，避免重复计费。不要关闭证书校验、全局更改代理或删聊天。

已验证：进程级代理fixture覆盖生成/解码/预览、诊断、Codex与WorkBuddy密钥检查、curl下载、系统旁路、无代理直连、407和302不自动回退；正式域名真实出图证据见发布记录。故障电脑的实际桌面显示仍需本清单验收。
